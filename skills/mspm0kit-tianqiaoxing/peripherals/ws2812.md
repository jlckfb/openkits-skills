# WS2812 RGB LED on Tianqiaoxing G3519

**Driver**: `hardware/hw_ws2812.c/h`（参考全功能固件）

## Hardware

- LED: 4× WS2812B 可寻址 RGB（板载，菊花链）
- 控制: TIMA1 CCP0 PWM on **PB26** + DMA
- 协议: 单线 800 kHz NZR
- **时钟要求: 必须 80 MHz**（period=100 → 800kHz）。32 MHz 下 PWM 只有 320kHz，T0H 高电平超阈值 → **全白**

> ⚠️ **全白 = bit 全被读成 1 = 时钟不对**。先 grep `CPUCLK_FREQ` 确认是 80000000（见 SKILL.md Clock 段）。

## 实现原理（PWM + DMA，实测可用）

- PWM period = 100（80 MHz / 100 = 800 kHz）
- DMA 在每个 timer 零事件把比较值写入 CC 寄存器：T0H=35（0 码），T1H=70（1 码）
- buffer 尾部留 50 个 T0H 作为复位间隔
- CC 更新方式必须设为 `ZERO_EVT`，防止 mid-cycle 写入导致 bit 错乱

## SysConfig 配置

**时钟（80 MHz，见 SKILL.md Clock 段，含 `SYSCTL.clockTreeEn = true`）**

**TIMA1 PWM**
```js
const PWM  = scripting.addModule("/ti/driverlib/PWM", {}, false);
const PWM1 = PWM.addInstance();
PWM1.$name                          = "WS2812";
PWM1.ccIndex                        = [0];
PWM1.pwmMode                        = "EDGE_ALIGN_UP";
PWM1.timerCount                     = 100;
PWM1.timerStartTimer                = true;
PWM1.PWM_CHANNEL_0.initVal          = "HIGH";
PWM1.PWM_CHANNEL_0.shadowUpdateMode = "ZERO_EVT";
PWM1.peripheral.$assign             = "TIMA1";
PWM1.peripheral.ccp0Pin.$assign     = "PB26";
PWM1.ccp0PinConfig.direction        = scripting.forceWrite("OUTPUT");
```

## 核心驱动代码

```c
#define WS2812B_NUM 4
#define DATA_SIZE   24
#define T0H         35
#define T1H         70
#define BUF_LEN     (DATA_SIZE * WS2812B_NUM + 50)

static uint32_t ws_buffer[BUF_LEN] = {0};

static void ws2812_init(void) {
    DL_SYSCTL_disableSleepOnExit();
    NVIC_EnableIRQ(DMA_INT_IRQn);
    DL_Timer_enableEvent(WS2812_INST, DL_TIMER_EVENT_ROUTE_1, DL_TIMER_EVENT_ZERO_EVENT);
    DL_Timer_setPublisherChanID(WS2812_INST, DL_TIMER_PUBLISHER_INDEX_0, 1);
    DL_DMA_setSubscriberChanID(DMA, DL_DMA_SUBSCRIBER_INDEX_0, 1);
    DL_TimerA_setCaptCompUpdateMethod(WS2812_INST,
        DL_TIMER_CC_UPDATE_METHOD_ZERO_EVT, DL_TIMERA_CAPTURE_COMPARE_0_INDEX);
    DL_DMA_setDestAddr(DMA, DMA_CH0_CHAN_ID,
        (uint32_t)&WS2812_INST->COUNTERREGS.CC_01[GPIO_WS2812_C0_IDX]);
    DL_DMA_disableChannel(DMA, DMA_CH0_CHAN_ID);
    for (int i = 0; i < BUF_LEN; i++) ws_buffer[i] = T0H;
    WS2812_INST->COUNTERREGS.CC_01[GPIO_WS2812_C0_IDX] = 1;
    DL_Timer_startCounter(WS2812_INST);
}

/* grb: bit23-16=G, 15-8=R, 7-0=B */
static void ws2812_write(uint16_t num, uint32_t grb) {
    if (num > WS2812B_NUM) num = WS2812B_NUM;
    for (uint8_t j = 0; j < num; j++)
        for (uint8_t i = 0; i < DATA_SIZE; i++)
            ws_buffer[i + j*DATA_SIZE] = ((grb << i) & 0x800000) ? T1H : T0H;
}

static void ws2812_send(void) {
    DL_DMA_disableChannel(DMA, DMA_CH0_CHAN_ID);
    DL_DMA_setSrcAddr(DMA, DMA_CH0_CHAN_ID, (uint32_t)ws_buffer);
    DL_DMA_setTransferSize(DMA, DMA_CH0_CHAN_ID, BUF_LEN);
    DL_Timer_disableEvent(WS2812_INST, DL_TIMER_EVENT_ROUTE_1, DL_TIMER_EVENT_ZERO_EVENT);
    DL_Timer_enableEvent(WS2812_INST, DL_TIMER_EVENT_ROUTE_1, DL_TIMER_EVENT_ZERO_EVENT);
    __disable_irq();
    DL_DMA_enableChannel(DMA, DMA_CH0_CHAN_ID);
    while (DL_DMA_getTransferSize(DMA, DMA_CH0_CHAN_ID) > 0) { ; }
    __enable_irq();
    DL_DMA_disableChannel(DMA, DMA_CH0_CHAN_ID);
    WS2812_INST->COUNTERREGS.CC_01[GPIO_WS2812_C0_IDX] = 1;
}

void DMA_IRQHandler(void) {
    if (DL_DMA_getPendingInterrupt(DMA) == DL_DMA_EVENT_IIDX_DMACH0) {
        DL_DMA_disableChannel(DMA, DMA_CH0_CHAN_ID);
    }
}
```

调用：`ws2812_write(4, 0x001E00); /* 80us settle */ ws2812_send();`（GRB，0x001E00 = 暗红）

## 注意

- DMA channel ID 宏：`DMA_CH0_CHAN_ID`（grep `ti_msp_dl_config.h` 确认）
- 颜色顺序 **GRB**（不是 RGB）：bit23-16=Green, 15-8=Red, 7-0=Blue
- 刷新前 `delay_us(80)` 让上一帧完成复位
